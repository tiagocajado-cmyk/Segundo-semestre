### COMANDOS BÁSICOS

Autenticar via computador local no Github:
```
gh auth login
```
gh ropo clone nome-do-repositorio
```

Abrir VS Code:
```

code .
```


###Salvar no GITHub

preparar arquivos para salvar:
```

git add .
```

comando para versionar (salvar):
```
git commit -m "mensagem"

```

Enviar para o Github

git push
```

Baixar atualização para o github:

git pull
